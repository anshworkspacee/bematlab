# BEMATLAB Grocery — 20-page React starter

A responsive grocery storefront built with React, TypeScript, Vite and React Router.

## Pages included
1. Home
2. Shop All
3. Categories
4. Product Details
5. Deals
6. New Arrivals
7. Fruits
8. Vegetables
9. Dairy & Eggs
10. Bakery
11. Snacks
12. Beverages
13. Cart
14. Checkout
15. Order Confirmation
16. About Us
17. Contact
18. FAQ
19. Privacy Policy
20. Terms & Conditions

## Run locally
1. Extract the ZIP.
2. Open the extracted project folder in VS Code.
3. Open Terminal in that folder and run:
   `npm install`
4. Then run:
   `npm run dev`
5. Open the local URL Vite prints, usually `http://localhost:5173`.

## Notes
- Cart state is stored in localStorage.
- Checkout and contact forms are demo UI only.
- Real payment, authentication, inventory, email and order processing require a backend/payment provider.
- Product photography loads from Unsplash URLs, so internet access is required for those images.
